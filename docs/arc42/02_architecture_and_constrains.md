# 2 - Architecture Constraints

The constraints are divided into requirements defined by the course and technical decisions made by the project team.

## 2.1 Technical Constraints

The following constraints were selected by the project team.

| ID | Constraint | Explanation |
|----|--------------|---------------|
| TC1 | Open source technologies | Only open-source frameworks and tools should be used |
| TC2 | MVC Architecture Pattern | The backend architecture must follow the Model-View-Controller (MVC) pattern |
| TC3 | Python Backend | The backend must be implemented using Python |
| TC4 | External API Integration | Movie information must be retrieved from the TMDB API |
| TC5 | Docker-based Deployment | The application must be deployed using Docker |

## 2.2 Organizational Constraints

The following constraints were defined by the course instructor.

| ID | Constraint | Explanation |
|----|--------------|---------------|
| OC1 | Public GitHub repository | The project must be developed in a publicly accessible GitHub repository |
| OC2 | Published documentation | The project documentation must be available on Read the Docs |
| OC3 | Static code analysis | The project must use a static code analysis tool |
| OC4 | Architecture Decision Records | Important architecture decisions must be documented as ADRs |
