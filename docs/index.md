# Welcome to MovieTracker Documentation

MovieTracker is a web application for discovering, tracking, and reviewing movies. It was designed and implemented as the final project for the **Software Quality Assurance** course, with a strong focus on software architecture, quality attributes, automated testing, and modern development practices.

The application allows users to search for movies, view detailed information, manage a personal watchlist, and share reviews, while integrating with the TMDB API to provide up-to-date movie data.

## Getting Started

If you want to run MovieTracker locally, begin with the [Quick Start Guide](installation.md), which explains the prerequisites, installation steps, and available deployment modes.
